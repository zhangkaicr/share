# 译文站点规范（share 项目）

## 目标读者
医学研究者 / 临床研究工作者。他们熟悉流行病学与生物统计，但不一定熟悉机器学习术语。
译文要让他们能读懂，并在关键处补充「背景与解释」。

## 通用要求
1. **全文中文化**：所有正文、标题、图注、表头、代码注释均译为中文。
2. **保留原文结构**：章节层级（h2/h3）、列表、表格、代码块、公式、图片、脚注锚点，一律保留，不得删减。
3. **专业术语**：首次出现用「中文（English）」格式，例如「倾向得分（propensity score）」「条件平均处理效应（CATE）」。
4. **代码不翻译语法**：R 函数名、参数名、包名保持原样；代码中的注释与字符串可译为中文；控制台输出里的英文提示保留原样（避免误导），但可在输出后加一句中文说明。
5. **公式**：保留 LaTeX 原文不动，周围说明文字译为中文。
6. **图片**：保留 `<img>` 与原始 src（已绝对化为原站 URL，不要改动）。
7. **链接**：指向原站/原文的链接保留；站内锚点（`#xxx`）若对应中文标题，需同步改为中文锚点的 id。

## 必须添加的「背景与解释」框
在以下位置插入说明框（用下面的 HTML 结构）：
- 每个关键方法/概念首次出现处（例如 metalearner、RMST、删失、SuperLearner、交叉验证、协变量平衡、重叠性）
- 读者可能卡住的代码步骤
- 输出结果的解读处（例如「这张图/表说明什么」）

说明框 HTML（放在 `.content` 内、相关段落之后）：

```html
<div class="note">
  <span class="nt">背景与解释</span>
  <p>……面向医学研究者补充的铺垫：这个概念在流行病学里对应什么、临床研究里为什么重要、常见误区……</p>
</div>
```

每页至少 3–6 个说明框，每个 2–5 句，言之有物，不要空话。

## 页面骨架
复制同目录下的 `_template.html`，替换三处占位符：
- `__TITLE__`：中文标题
- `__SUBTITLE__`：原文出处、作者、日期、许可信息，以及「非官方中文译本，引用请以英文原文为准」
- `__FOOTER__`：返回链接 + 原文链接 + 声明

正文放进 `<div class="content">` 内。

**不要修改** `<head>` 里的主题切换脚本、MathJax 配置和 CSS 变量——它们保证全站明暗主题一致。

## 目录页（index.html）要求
多页站点需有一个总览 `index.html`：
- 一句话定位这个包解决什么问题
- 分篇卡片列表（链接到同目录各页面）
- 一个「术语对照」小节（关键英文术语 → 中文）
- 阅读顺序建议

## 禁止
- 不得出现 `TODO`、`待翻译`、`[翻译]` 等占位符
- 不得整段漏译（每段英文都必须在中文里出现对应内容）
- 不得改动主题切换代码
- 不得引入外部 CSS/JS（MathJax 除外，已在模板中）

## 完成后自检
运行 `python _tools/validate.py <页面.html>`，必须全部通过。
